## 理论与建模指导

- 建模顺序应保持为：参数 -> 几何 -> 选择集 -> 材料 -> 物理场 -> 边界/初始条件 -> 网格 -> 研究/求解 -> 结果导出。
- 生成代码中的边界编号和选择集必须在 COMSOL 中复核；学习库只能提供案例模式和 API 结构，不能替代几何实体编号确认。
- 几何模型与参数指导：几何与参数应优先按“传热几何与参数 + 水力压裂单孔/裂隙几何”组织。 先按几何厚度选择 2D 或 3D；薄板可用 2D，实体散热优先 3D
- 几何要点：矩形/块体热传导域；热源区域；冷却或对流边界；温度监测点或输出边界；矩形或正方形煤/岩体代表试验工作面或局部煤层；中心或指定位置圆形钻孔。
- 关键参数建议：N=20（Spatial frequency resolution）；b=1.8（Spectral exponent）；D=2+(3-b)/2（Fractal dimension）；T_init=20[degC]（磁滞作用下的相变建模）；dT=1[K]（磁滞作用下的相变建模）；T_melt=65[degC]（磁滞作用下的相变建模）；T_freeze=55[degC]（磁滞作用下的相变建模）；T_top=T_melt+dT/2（磁滞作用下的相变建模）。
- 选择集与扫描建议：选择集=命名热源域；命名固定温度边界；命名对流边界；命名输出点/面；命名钻孔边界；命名外边界四边；扫描变量=Q0、hconv、L、W、pinj、sigH。
- 材料与物性参数指导：材料与物性参数应优先按“电学材料 + 传热材料 + 结构力学材料”配置。 Recognized material: Copper.
- 必填物性：电导率(sigma, S/m)；密度(rho, kg/m^3)；导热系数(k, W/(m*K))；比热容(Cp, J/(kg*K))；弹性模量(E, Pa)；泊松比(nu, 1)。
- 物性变化关系：电导率常随温度变化；频域问题中介电常数和损耗因子可能随频率变化。；导热系数、比热和密度可随温度变化；复合材料导热系数可能随方向变化。；弹性模量和强度可为空间随机场；复合材料或层状材料需要方向相关弹性矩阵。。
- 边界条件与初始条件指导：按当前需求，边界条件应优先按“传热 + 电流/静电 + 固体力学”来判断。
- 建议边界：固定温度/给定温度；热通量或热源；绝热/对称；对流换热；表面对表面或环境辐射；端子电压或电流；接地；电绝缘。
- 建议初始条件：初始温度；初始热源状态；环境温度；初始电势；初始电荷分布；初始电流状态。
- 物理场复合场检查：该需求应按复合场判断，优先考虑：电-热耦合 / 焦耳热 + 热-结构耦合 / 热应力 + 非等温流动 + 孔压-应力-裂缝耦合。 主物理场=Electric Currents；耦合物理场=Heat Transfer in Solids、Solid Mechanics、Heat Transfer in Fluids、Darcy's Law / Porous Media Flow、Fracture Flow、Phase Field or Cohesive Zone；多物理场节点=Joule Heating / Electromagnetic Heating、Thermal Expansion、Nonisothermal Flow、Poroelasticity、Fracture flow-stress coupling。
- 传热模型需要确认热源、温度边界、热通量或对流换热条件，并检查材料的导热系数、密度和热容。
- 电流/电磁模型需要确认端子、电势、接地和绝缘边界；若与传热耦合，应把焦耳热或损耗项传递到热场。
- 参数扫描说明：代码中的 1-5 V 仅为待审核默认范围，必须按已确认的工况替换后再求解。
- 流体模型需要确认入口、出口、壁面和压力条件；微流动案例通常还要同时检查稀物质传递或扩散系数。
- 结构力学模型需要确认固定约束、载荷、接触/对称条件和材料弹性参数；特征频率问题应使用 Eigenfrequency 研究。
- 已学习案例中的理论关键词包括：传热，电磁，多孔介质/裂隙，电流守恒，焦耳热，能量守恒，热传导，热膨胀，热应力，稳态导热，对流换热，参数扫描。
